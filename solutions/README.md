## How to Use

Each `solution.py` contains a Python implementation of the core data structures
and algorithms discussed in the corresponding `problems/` walkthrough.

These are **educational implementations** — they demonstrate the key concepts
but are not production-ready.

## Running Solutions

```bash
cd solutions/easy/url-shortener
python solution.py
```
