# Medium Problems

Require juggling multiple distributed systems concerns simultaneously.

| Project | Key Concepts |
|---------|-------------|
| [Distributed Rate Limiter](distributed-rate-limiter/README.md) | Token bucket, Redis Lua, distributed counters |
| [Notification System](notification-system/README.md) | Fan-out, channel routing, retry queues |
| [Realtime Chat System](realtime-chat-system/README.md) | WebSockets, message ordering, presence |
| [Ticket Booking System](ticket-booking-system/README.md) | Optimistic locking, saga, seat inventory |
| [Twitter Newsfeed](twitter-newsfeed/README.md) | Fan-out write vs read, timeline cache |

**Typical interview time:** 45-60 minutes  
**Goal:** Identify the hardest sub-problem, go deep on one trade-off area.
