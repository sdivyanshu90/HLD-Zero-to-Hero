# Easy Problems

Foundational distributed systems design problems. These should be comfortable
after completing the [modules/](../../modules/) study track.

| Project | Key Concepts |
|---------|-------------|
| [URL Shortener](url-shortener/README.md) | Hash generation, redirect caching, analytics |
| [Distributed Cache](distributed-cache/README.md) | Eviction policies, consistent hashing, persistence |
| [Distributed ID Generator](distributed-id-generator/README.md) | 64-bit layout, clock skew, sequence overflow |

**Typical interview time:** 30-45 minutes  
**Goal:** Derive requirements, BoE math, core data model, handle 1-2 hard sub-problems.
