# Interview Framework

A strong system design interview answer follows a controlled sequence instead of random brainstorming.

## Recommended Timing

- 5 minutes requirements
- 5 minutes math
- 5 minutes API design
- 10 minutes high-level design
- 15 minutes deep dives
- 5 minutes wrap up

## Why It Works

This structure forces clarity early and prevents beautiful diagrams built on wrong assumptions.

## Real-World Analogy

It is an execution plan for a consulting meeting: clarify the ask, size the work, define the interface, present the architecture, defend the details, then close cleanly.

## Interview Use

If you get lost, return to the framework. It keeps the conversation organized and buys credibility.
